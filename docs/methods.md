# 方法说明：预测、规则与奖励分别负责什么

## 两种觅食方法

| 维度 | A：heuristic | B：qlearn |
|---|---|---|
| 通俗理解 | 按写好的导航规则走 | 尝试行动，按奖励修改动作评分表 |
| 学习的内容 | 共享运动模型学习坐标变化；觅食规则本身不学习 | 觅食动作的 Q 值 |
| 决策来源 | 不饿时好奇心探索，饿时找食物 | epsilon-greedy：有时随机尝试，否则选择 Q 值最大的动作 |
| 导航依据 | 当前默认使用环境真实下一步；保留模型导航的代码开关 | 压缩后的状态与 Q 表 |
| 主要实现 | agents/heuristic.py | agents/qlearn.py |
| 选择方式 | --policy heuristic，默认 | --policy qlearn |
| 保存什么 | 统计与参数；Q 表为空 | 统计、参数和 Q 表 |
| 未实现的能力 | 不会自己学出新的觅食规则 | 没有独立测试期、统一续训或高层避敌决策 |

## 共享组件不是第三个完整版本

agents/curiosity.py 用模型预测下一步，把较少访问的位置记为更“新颖”，再减去无效动作和循环访问的惩罚。它是一套手工定义的探索打分，不是预测误差驱动的完整内在奖励训练器。

models.py 的 ForwardModel 是一个纯 Python 小型神经网络（MLP）。输入来自坐标与动作，不是渲染图像；buffer.py 虽然保存图像，训练数组并不把图像送进模型。图像主要服务于视野展示。

运动模型默认在独立 motion 阶段训练。forage 默认 motion_epochs_per_day=0，不继续更新运动模型；显式开启该参数才做额外运动训练。这项训练仍不同于 Q 表更新。

## Q-learning 当前的具体定义

状态特征有六项：粗网格 x、y，是否饥饿，目标食物方向的两个符号，以及剩余饥饿时间的分桶。

每步基础奖励 -0.01；在适用的饥饿状态下加上 -0.05 × 到目标食物的距离；吃到食物 +10；死亡 -10。终止时不加入下一状态 Q 值，否则使用折扣后的最大下一状态 Q 值更新。

该距离项是对剩余距离扣分，不是“每靠近一步就奖励”的距离差。特征会在食物记忆为空时回退完整食物地图；它不等同于严格的有限视野策略。

默认动作保留 4 个腿编号 × 4 个移动方向 × 2 个转向，共 32 种编码。单格环境中腿编号和转向对位置转移没有区别，多个编码对应同一个移动结果，增加了 Q 表需要探索的冗余。

## 当前信息与评估边界

A 能从完整 food_cells 选食物，用真实 peek_step 检查动作；共享好奇心也用真实环境检查无效移动。B 的特征及奖励计算也可访问完整食物位置。这些更接近带内部信息的基线，不能以视野半径参数证明只用了局部观测。

B 每次运行新建 Q 表，保存表格但暂不提供统一的 forage --resume。训练期间 epsilon 会衰减，本次运行观察也包含探索动作；没有冻结策略后在独立 seed / 地图上测试。因此 A/B 数字只描述本次预算下的表现。

## 当前 evade 的位置

evade_train.py 组合两条规则：看到敌人且有草丛目标时向草丛走，否则执行规则觅食和探索。它没有 --policy qlearn 切换，不更新 Q 表，也不训练高层“觅食还是逃跑”的策略。

forage checkpoint 中的 Q 表不会自动接入 evade。不要把“可接受 forage checkpoint”理解成“已经实现学习型联合生存”。

## 占位与计划

imitation 目前回退 heuristic 并给出警告，不是训练好的模仿学习方法。Survival 元策略、独立 Survival UI 和优化器尚未实现，状态以 [实现清单](status.md) 为准。
